# Bully PC recovery project rules

Read README, HANDOFF, docs/TARGET, docs/COVERAGE and docs/PROVENANCE first.
Follow current shared owner rules and the pinned decompilation skill.

- Scope is full original-engine PC Scholarship Edition recovery. No Unreal
  remake or Xbox 360 substitution. Milestones do not replace the full-game goal.
- Work on a task branch. No main merge/push without explicit owner authorization.
- Current target hash is mandatory for any address-dependent analysis.
- Retail files, raw decompiler/disassembly output, databases, generated game code,
  memory dumps, private model logs, credentials and personal paths remain local.
- Never print raw proprietary evidence into cloud tool responses. Review minimized
  metadata and independently written specifications separately.
- Do not alter original installation/saves or another project's files/processes.
  Preserve all unrelated workloads. No Ghostty control, duplicate drivers or
  unsolicited model-server/credential/security changes.
- No paid APIs, subscriptions, model deletion or large model installs. Inspect
  existing tools/weights read-only first. Report bounded setup options if needed.
- No inferred model identity, binary match, recovered function or runtime success.
  Synthetic fixture passes do not advance game-function coverage.
- Retain failures; distinguish inventoried, analyzed, implemented, compiled,
  original-oracle-tested and binary-matched counts with actual denominators.
- Review staged files and reachable history before each public push. Explicitly
  stage reviewed files. Record source licenses/notices before any reuse.
- Keep HANDOFF and evidence current. A raw instruction/address count is not a
  progress percentage. Do not install an unattended loop as an incidental step.
